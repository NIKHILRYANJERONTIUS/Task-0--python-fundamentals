 IEEE AI/ML Python Fundamentals Task

Overview

This repository contains solutions for the IEEE AI/ML Python Fundamentals assignment.

The project covers:
- Python Fundamentals
- Functions and Loops
- Prime Number Checking using `for-else`
- NumPy Basics
- Pandas CSV Analysis
- Data Visualization using Matplotlib
